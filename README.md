Customer churn is a major challenge for businesses because losing existing customers can affect revenue and long-term customer relationships. This project presents a machine learning-based Customer Churn Prediction system that predicts whether a customer is likely to churn based on customer and service-related information. The project uses a Telco Customer Churn dataset and applies data preprocessing, exploratory data analysis, feature selection, and multiple machine learning algorithms, including Logistic Regression, Decision Tree, Random Forest, K-Nearest Neighbors, Support Vector Machine, Gradient Boosting, and XGBoost. SHAP is used to provide model explainability by identifying important features contributing to churn predictions. The trained XGBoost model is integrated into a Flask web dashboard where users can enter customer information and receive a churn prediction and probability. The system also provides a retention strategy for customers identified as being at higher risk of churn. Thus, the project combines churn prediction, explainable machine learning, web deployment, and customer retention recommendations in a single application.
